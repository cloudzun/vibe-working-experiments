# response-generator

**功能**: 根据 RFP 需求和答案生成投标响应文档（Word 格式）

**触发词**:
- "生成投标响应"
- "生成 Word"
- "生成文档"
- "投标文档"

**输入**: 需求清单 + 答案对照表

**输出**: Word 文档（.docx）

**示例**:
```
用户：根据上面的需求和答案，生成投标响应文档

AI:
✅ 文档生成完成！

**文件**: VanArsdel_RFP_Response.docx
**位置**: outputs/
**大小**: 42 KB

文档包含：
1. 封面页
2. 执行摘要
3. 技术响应
4. 商务响应
5. 实施计划
```

**执行步骤**:
1. 准备需求 - 答案配对
2. 生成 Python 脚本（使用 python-docx）
3. 创建 Word 文档（封面 + 目录 + 正文）
4. 保存到 `outputs/` 目录

**纪律**:
- ✅ 只使用已找到的答案
- ❌ 不编造数据
- ⚠️ 缺失答案标注 `[需补充]`
