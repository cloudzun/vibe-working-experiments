# knowledge-searcher

**功能**: 在产品文档中检索答案，为 RFP 需求找到对应支持

**触发词**:
- "找答案"
- "检索答案"
- "在产品文档中"
- "查找产品文档"

**输入**: 需求列表 + 产品文档目录（如 `materials/`）

**输出**: 需求 - 答案对照表（Markdown 表格）

**示例**:
```
用户：请在产品文档中检索这些需求的答案

AI:
## 需求 - 答案对照表

| 需求 | 答案来源 | 关键内容 | 置信度 |
|------|---------|---------|--------|
| [需求 1] | Technical_Specifications.docx | [答案摘要] | 高 |
...

✅ 找到 X 个答案
⚠️ Y 个需求需人工补充
```

**执行步骤**:
1. 读取所有产品文档（.docx, .xlsx）
2. 为每个需求提取关键词
3. 在文档中搜索匹配内容
4. 标注来源和置信度
