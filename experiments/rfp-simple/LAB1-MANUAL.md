# Lab 1: RFP Response Agent - 自然语言交互实验

> **实验目标**：加载预置 Skill，用自然语言让 AI 分析 RFP 并生成响应  
> **预计时间**：15 分钟  
> **前提**：无需写代码，只需会聊天

---

## 🎯 场景背景

你是公司的销售工程师，收到了 VanArsdel 公司的 RFP（招标文件）。

**你的任务**：
1. 理解 RFP 中的 21 个需求
2. 从 5 个产品文档中找到对应答案
3. 生成一份完整的投标响应文档

**传统方式**：需要 2-3 天人工阅读和整理  
**AI 方式**：15 分钟完成初稿

---

## 📦 预置 Skill 清单

实验前已为你准备好以下 Skill：

| Skill 名称 | 功能 | 文件 |
|-----------|------|------|
| `rfp-analyzer` | 分析 RFP 文档，提取需求 | `skills/rfp-analyzer.yaml` |
| `knowledge-searcher` | 在产品文档中检索答案 | `skills/knowledge-searcher.yaml` |
| `response-generator` | 生成投标响应文档 | `skills/response-generator.yaml` |

**你不需要**：
- ❌ 编写 Python 脚本
- ❌ 理解 JSON 结构
- ❌ 手动提取数据

**你只需要**：
- ✅ 用自然语言描述需求
- ✅ 检查结果是否满意
- ✅ 微调不满意的地方

---

## 🚀 实验步骤

### Step 1：加载 Skill（2 分钟）

**操作**：打开 OpenCode Desktop，加载预置 Skill

**方式 A：使用预配置 Agent**
```
在 OpenCode 中输入：
/agent load rfp-response-agent
```

**方式 B：手动加载 Skill**
```
在 OpenCode 中输入：
/skill load skills/rfp-analyzer.yaml
/skill load skills/knowledge-searcher.yaml
/skill load skills/response-generator.yaml
```

**预期结果**：
```
✅ 已加载 3 个 Skill
✅ RFP Response Agent 已就绪
```

---

### Step 2：分析 RFP 需求（3 分钟）

**你的指令**：
```
请帮我分析这个 RFP 文件，找出所有的需求：
materials/VanArsdel_RFP.docx
```

**AI 自动执行**：
1. 读取 RFP 文档
2. 识别 21 个需求
3. 分类整理（技术/商务/实施）
4. 输出结构化清单

**预期输出**：
```markdown
## RFP 需求分析

### 技术需求（12 个）
1. 部署可扩展的能源管理平台
2. 集成 IoT 传感器（温度、 occupancy、湿度等）
3. 支持云端管理门户和移动访问
...

### 商务需求（5 个）
1. 提供详细的价格清单
2. 说明付款条件
3. 提供客户案例参考
...

### 实施需求（4 个）
1. 安装所有必要硬件和软件
2. 培训物业员工
3. 提供持续支持
...
```

**如果不满意**，可以用自然语言调整：
```
"请把需求按优先级排序，标记出最关键的前 5 个"
"请帮我找出哪些需求我们可能无法满足"
```

---

### Step 3：检索产品知识（5 分钟）

**你的指令**：
```
请在我们的产品文档中，找出能回答这些需求的内容。
产品文档在 materials/ 目录下。
```

**AI 自动执行**：
1. 读取 5 个产品文档
2. 对每个需求检索相关段落
3. 标注来源（哪个文档的哪一页）
4. 按相关性排序

**预期输出**：
```markdown
## 需求 - 答案对照表

| 需求 | 答案来源 | 关键内容 |
|------|---------|---------|
| 部署能源管理平台 | Technical_Specifications.docx P3 | EcoSense 360 是云端平台... |
| 集成 IoT 传感器 | Technical_Specifications.docx P5 | 支持无线传感器... |
| 提供价格清单 | Sample_Pricing_Sheet.docx P1 | 基础版$99/月... |
...
```

**如果不满意**，可以调整：
```
"答案太简单了，请找更详细的说明"
"这个需求没有找到答案，请标记为'需人工补充'"
"请帮我找出我们比竞争对手的优势在哪里"
```

---

### Step 4：生成响应文档（5 分钟）

**你的指令**：
```
请根据上面的需求和答案，生成一份完整的投标响应文档。
格式要专业，适合发给客户。
```

**AI 自动执行**：
1. 组织 21 个问答对
2. 添加封面和目录
3. 格式化排版
4. 生成 Word 文档

**预期输出**：
```
✅ 已生成响应文档：rfp_response.docx
📄 共 15 页，包含：
   - 封面（公司信息）
   - 目录
   - 执行摘要
   - 技术响应（12 个需求）
   - 商务响应（5 个需求）
   - 实施计划（4 个需求）
   - 附录（客户案例、资质证书）
```

**如果不满意**，可以调整：
```
"语气太技术化了，请改得更商务一些"
"请添加一个执行摘要，突出我们的优势"
"价格部分请隐去，我手动填写"
"请生成 PDF 版本"
```

## 🔧 Skill 工作原理（选读）

### rfp-analyzer Skill

```yaml
name: rfp-analyzer
description: 分析 RFP 文档，提取需求

处理流程:
1. 读取 Word/PDF 文档
2. 识别列表项（List Bullet）
3. 匹配动词开头（Deploy/Integrate 等）
4. 分类整理（技术/商务/实施）
5. 输出 Markdown 清单
```

### knowledge-searcher Skill

```yaml
name: knowledge-searcher
description: 在产品文档中检索答案

处理流程:
1. 读取多个产品文档
2. 提取问题关键词
3. 计算相关性得分
4. 返回 Top 3-5 个答案
5. 标注来源
```

### response-generator Skill

```yaml
name: response-generator
description: 生成投标响应文档

处理流程:
1. 组织问答对
2. 添加封面和目录
3. 格式化排版
4. 生成 Word/PDF
```

## 💡 进阶技巧

### 技巧 1：指定输出格式

```
"请用表格形式整理需求和答案"
"请生成 PPT 格式的执行摘要"
"请输出 Markdown 格式，方便我编辑"
```

### 技巧 2：添加公司特色

```
"请在回答中强调我们的 AI 技术优势"
"请突出我们在酒店行业的成功案例"
"请说明我们的本地化支持能力"
```

### 技巧 3：风险识别

```
"请找出哪些需求我们可能无法满足"
"请标记出需要技术团队确认的内容"
"请评估这个项目的风险点"
```

### 技巧 4：竞品对比

```
"请对比我们的方案和竞争对手的优势"
"请找出我们的差异化特点"
"请说明为什么客户应该选择我们"
```

## 📝 常见问题

### Q1: 如果 Skill 提取的需求不准确怎么办？

**A**: 用自然语言告诉 AI：
```
"第 5 个需求理解错了，应该是...请重新提取"
"请忽略格式要求，只关注功能需求"
```

---

### Q2: 如果产品文档中没有某个需求的答案怎么办？

**A**: AI 会标记为"需人工补充"，你可以：
```
"请帮我想一个合理的回答草稿"
"请标记为黄色，我稍后手动填写"
"请从竞争对手的网站找参考答案"
```

---

### Q3: 如何保存和复用这个 Skill？

**A**: 
```
"请帮我把这个 Skill 保存为模板"
"下次有类似的 RFP，我如何快速调用？"
"请生成 Skill 的配置文件，我分享给同事"
```

---

### Q4: 可以微调 Skill 的行为吗？

**A**: 可以！用自然语言描述：
```
"请只提取技术需求，商务需求我自己处理"
"请忽略金额小于 10 万的项目"
"请优先匹配最近 3 年的案例"
```
